# Internship BEM Website Project

TaskFlow adalah aplikasi manajemen proyek dan tugas berbasis HTML, CSS, dan JavaScript.

Jalankan server lokal dari folder ini dengan `python -m http.server 8000`, lalu buka `http://localhost:8000`.

Versi awal menyimpan proyek, tugas, dan tema di browser. Login, lampiran, drag-and-drop, ekspor, dan cache offline belum tersedia. Data browser tidak tersinkron dan dapat hilang jika data situs dibersihkan.
