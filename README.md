# Internship BEM Website Project

TaskFlow adalah aplikasi manajemen proyek dan tugas berbasis HTML, CSS, dan JavaScript.

Jalankan server lokal dari folder ini dengan `python -m http.server 8000`, lalu buka `http://localhost:8000`.

Proyek dan tugas disimpan terpisah untuk setiap akun lokal; lampiran hingga 5 MB disimpan di IndexedDB. Ada peringatan tenggat dan pilihan impor untuk data dari versi awal. Data tidak tersinkron dan dapat hilang jika data situs dibersihkan. Akun lokal bukan perlindungan data dari orang yang memiliki akses ke perangkat atau profil browser yang sama.

Drag-and-drop, ekspor, dan cache offline belum tersedia. Aplikasi memerlukan HTTPS atau localhost untuk autentikasi.
